# Web UI 标准

## 1. 范围

生产 Web 由 `product/frontend/` 的 React 应用统一提供，固定九项主导航：

| 顺序 | 页面 | 路由 |
| ---: | --- | --- |
| 1 | 首页 | `/` |
| 2 | 自选 | `/watchlist` |
| 3 | 策略 | `/screener` |
| 4 | 次日计划 | `/next-plan` |
| 5 | 当日实盘 | `/live-trading` |
| 6 | 复盘 | `/review` |
| 7 | 回测 | `/backtest` |
| 8 | 个股分析 | `/stock-analysis` |
| 9 | 设置 | `/settings` |

旧 Policy `/strategy`、`/monitor`、`/research` 页面只属于本地兼容研究服务，不是生产
产品入口，不再单独维护一套现行视觉规范。

## 2. 设计系统

- 页面复用 `product/frontend/src/index.css`、共享组件和 Tailwind 配置。
- 正文使用系统中文无衬线字体；代码、时间和版本使用等宽字体。
- 字号不随视口宽度缩放，字距固定为 `0`。
- 页面区块使用全宽或无框布局；卡片只用于重复条目、模态框和真正需要边界的工具。
- 不使用卡片嵌套、装饰性渐变球或纯营销式大标题。
- 图标按钮优先使用已有 Lucide 图标，并提供可访问名称或 Tooltip。
- 固定格式控件使用明确尺寸、网格或 `aspect-ratio`，动态内容不得推动布局跳变。

## 3. 共享交互

| 场景 | 要求 |
| --- | --- |
| 导航 | 桌面侧栏默认展开并可收缩为图标栏；移动端使用抽屉 |
| 加载 | 保留上一份有效数据，避免把加载态显示为业务零值 |
| 空态 | 区分未配置、无权限、无数据、任务运行中和依赖失败 |
| 错误 | 页面内显示可诊断信息；Policy 依赖失败不得触发全局退出 |
| 表格 | 仅表格容器横向滚动，页面本身不得横向溢出 |
| 表单 | 新建与编辑状态隔离，关闭或成功后清理临时状态 |
| 任务 | 显示持久任务 ID、进度、终态和失败原因 |
| 实时 | 显示源时间、更新时间和新鲜度；SSE 断连后重查 REST |
| 权限 | 隐藏入口不能替代服务端授权，拒绝状态必须明确 |

## 4. 响应式与可访问性

- 必测桌面视口 `1440x1000` 和窄屏 `390x844`。
- 菜单按钮、标题、右侧操作和状态信息不得重叠。
- 长文本换行；按钮文字和图标不能溢出容器。
- 数据密集页面保持可扫描，不把表格强制转换为装饰卡片。
- 所有交互控件具有可见的焦点状态和键盘操作路径。
- 状态和风险不能只用颜色表达，必须同时提供文字或图标。
- 模态框在窄屏仍可关闭、滚动和提交。

## 5. Policy 页面

次日计划和当日实盘通过同源 `/api/policy/*` 读取内嵌 Policy：

- 页面先渲染标题、日期、同步状态和空态，再加载依赖数据。
- 空安装没有激活计划时显示真实空态，不伪造候选。
- 刷新报告进入持久任务，完成前禁用重复操作。
- 行情过期、昨收不一致或依赖失败时暂停有效判断。
- 页面不显示服务间 Token、数据库地址或对象存储凭据。

## 6. 验收

前端变更至少执行：

```bash
cd product/frontend
pnpm test
pnpm lint
pnpm build
```

可见改动还需使用真实浏览器验证：

1. 登录、向导和九项路由。
2. 桌面侧栏展开/收缩和移动抽屉。
3. 加载、空、错、无权限和任务运行中状态。
4. 深色与浅色主题。
5. 桌面和 `390x844` 无遮挡、截断和页面级横向滚动。

2026-10-19 生产候选已完成新浏览器会话、九项页面刷新、桌面和窄屏基础验收；
这不代表全量行情、AI、SMTP 或真实回测业务已签收。
