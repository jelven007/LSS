# 主线龙头 V2.1 核心执行净收益回测

2026-10-15。区间：2026-08-11 至 2026-09-24，共 33 个交易日的 D1 候选，D2 入场、D3 起退出。回测使用 rustdx 真实分钟行情，计入费用、滑点与 A 股 T+1 约束。完整逐笔成交、逐日净值与参数见[回测结果 JSON](data/leader-v21-net-20261015/report.json)、[成交明细 CSV](data/leader-v21-net-20261015/trades.csv)。[1](#source-1)

## 结论先行

**本轮调整没有把负期望交易变成正期望。** 在相同的真实成交、费用与 T+1 约束下，所有方案 33 日组合净收益均为负或零：

- 新方案的核心候选筛选（仅前二持续主线常规龙头、评分 ≥60）配合旧触板买点，组合净 **−0.21%**，优于 V2 原版的 **−0.51%** 和 V1 的 **−0.30%**；较少交易、较低回撤与费用。
- 新方案的「开板后放量恢复此前高点」买点在本样本中 **0 笔成交**：真正的主线龙头确认强度后会直接回封封死，后续没有可成交的非涨停分钟，因此严格可买窗口被如实判定为不存在。
- 费用、滑点与无法成交的封板是净收益的决定因素，封板比例不能代表收益。新买点、启动强度、1.5 倍量比仍是**待前向验证的假设**，不是已验证的盈利参数。

33 天为开发与归因样本，且此前已多次查看，不构成样本外验证。本轮不发布生产镜像；线上仍运行 V1，V2.1 为开发/实验版本。

## 回测口径

同一套因果成交与退出协议作用于 V1、V2 与新核心的候选，确保比较的是选股与买点，而非口径差异。[2](#source-2)

- **候选**：用冻结的 V1/V2/V2.1 配置在每个 D1 收盘后重算题材排名与候选。V2.1 在评分和最终数量选择之前，只保留 `risk_reason=regular` 的常规核心龙头，不把被过滤的龙头跟风股顶上来。
- **买点（仅使用确认时点之前已完成的分钟）**：
  - 旧触板买点（`leader_execution_version=1`）：触板后出现有量、未封死、不低于昨收的分钟即视为可买窗口。
  - 新强度买点（版本 2）：触板→开板→放量重新突破开板后此前已观察的高点（分钟量比 ≥1.5）才确认；确认后仍需在**后续**有量、未封死、未跌破昨收的分钟才算成交，不用确认分钟自身的收盘价假定成交。
- **板块确认**：仅用同一分钟、同题材、D1 预先声明的涨停同伴的当时价格，样本 ≥2 且上涨比例 ≥50%。
- **退出**：D2 买入，T+1 下 D3 才能卖。−4% 保护止损为先触发阈值；跳空低于止损按实际开盘价成交，不用触不到的阈值当卖价；止损未触发则 14:55 发出、按 14:56 实际分钟价定时退出。另设「D3 早盘承接失败退出」独立对照。无法成交的跌停仓位继续盯市，不从样本删除。
- **组合**：10 万初始资金，按时序现金账本结算，卖出资金下一交易日才可复用（保守）。单票 10%、组合 20% 上限。委托不超过当分钟成交量的 1%。
- **费用**：双边各 0.1% 滑点、佣金各 0.03%（最低 5 元）、过户费各 0.001%、卖出印花税 0.05%。另做双边 0.2% 滑点压力测试。

两笔小幅盈利（扣费后分别 +0.26%、+2.55%）不足以覆盖一笔 −4.90% 的止损，是组合小幅为负的直接原因。退出方式对照无差异：唯一亏损笔在 D3 开盘后第 3 分钟（09:33）即触及 −4% 止损，早于 09:35 开始的早盘承接失败窗口，因此两种退出成交完全一致。

### 新买点为何 0 成交

28 个核心候选中，新强度买点下的处置：21 个竞价不合格（与旧买点相同的竞价区间）、4 个在截止前跌破昨收放弃、1 个炸板超限（603230，即旧买点那笔 −4.90% 的亏损——新买点将其直接否决）、2 个确认强度后无可成交窗口（`no_capacity_or_price_fill`）。

关键的两笔正是旧买点买到的 002418、002585：新买点在 09:46、09:47 以 3.24、2.17 倍放量确认了强度，但此后龙头回封封死，后续分钟全在涨停价，严格「后续可成交」规则如实判定买不进。换言之，新买点在本样本中**要么否决亏损笔、要么买不到盈利笔**，净效果是空仓。这不能证明新买点更好或更差——它需要在更多能观察到开板成交的样本上前向验证。

## 数据与验证边界

- 真实分钟行情经 rustdx 采集，662 个请求分钟对全部取回，日线无网络失败；原始选股快照 SHA256 与归一化帧哈希已记录在结果 JSON。[1](#source-1)
- 分钟线为采样收盘与成交量，无逐笔委托、买卖队列、秒级封稳与真实竞价撮合价；成交为保守的分钟级条件代理，不等同券商成交。
- D1 身份冻结；盘中龙头易主无法由 D1 涨停同伴子集完全验证。题材、流通股本与股票宇宙保留原始时点偏差与幸存者偏差。
- 33 天已多次查看，是开发数据，不是未触碰的样本外。本轮结论为开发样本回测，新参数只能作为下一轮前向实验假设。
- 费用为研究模型，实盘应替换为账户实际费率与成交滑点。
