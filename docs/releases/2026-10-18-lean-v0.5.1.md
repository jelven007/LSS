# 精简架构 v0.5.1 发布候选

日期：2026-10-18

版本：`0.5.1`

状态：源码候选，等待镜像构建、数据迁移和生产验收

## 变更

- Policy 以内嵌 ASGI 模块运行，移除生产独立 API 和 HTTP Bridge。
- 行情、特征、策略状态和 Redis 投影收敛到带 SQLite WAL 的 `market-worker`。
- TSP SSE 并入统一 API，四类后台任务由 `task-worker` 统一监督。
- TSP 与 Policy 共享 PostgreSQL 集群，控制库和业务库使用独立运行角色。
- 移除生产 Kafka、Flink、MinIO 和 Policy 报告 NAS。
- 对象存储迁移到火山引擎 TOS。
- DinD 替换为无密钥、禁止出网、只读文件系统的独立 `tsp-compute`。
- 两个 Rust 桥接统一锁定 crates.io `jelven-rustdx-complete 1.12.2`，构建不再需要
  GitHub 读取凭据。

## 兼容性

- Web 路由和 `/api/policy/*` 契约不变。
- Kafka/Flink 代码和本地 Compose 保留用于历史回归与紧急回滚。
- 旧 `tsp-postgres` PVC 在数据迁移和验收完成前必须保留。

- 公网健康、登录、九项菜单、Policy 页面、SSE、SMTP 和回测验收通过。
